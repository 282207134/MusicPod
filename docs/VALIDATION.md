- 删除 9 张未使用的导出图片及临时检查拼图；保留 68 个实际使用的图片/Logo 资源。
- 图片来源索引只保留文件、节点、名称与图片哈希；原稿文件与 App 运行截图分目录保存。

本项目为本地交互演示。真实短信、音乐流媒体、服务端下载、账号同步、社交、订阅购买、投放设备和 DSP 音效尚未接入。所有曲目共用原创试听音频；本地保存的设置不代表对应远端或平台功能已实现。详见根目录 README 的“演示范围”。
